# 四种论文类型详解（MPA）

MPA 选题不宜以企业内部经营管理、工程技术及设备管理为主要内容。先据决策树（见 SKILL.md）定类型，再按下表搭正文结构。

## 通用绪论要素（四类都要）
选题依据（背景+意义）→ 文献综述（研究与实践进展评述，指出不足，引出拟研究问题）→ 研究内容与主题 → 研究方法及技术路线。

---

## 1. 问题研究型
针对公共管理现实问题，运用理论与方法辨析问题、分析成因、提方案并可行性论证。

**正文结构**：绪论 → 理论基础（理论依据或框架建构论证）→ 现状描述/问题/成因分析 → 解决问题的新思路（可对比国内外方案，提可行性思路）→ 结论与建议。

**问题分析写作**：
1. 罗列文献中提到的问题；
2. 罗列实际工作中体会到的问题；
3. 归纳共性问题，把具体问题点纳入；
4. 据文献或工作实际改写/撰写存在的问题；
5. 说明解决问题的紧迫性。
围绕主题、因地制宜、结合论据、划分层次提问题。
> 常见病：问题与调查无关、过于宏大、缺论据、层次逻辑散乱；现状与问题混合；与公共管理专业无关。

**原因分析写作**：针对问题逐条；层层深入（表层/深层/根本）或从体制/机制/政策/规范多维度；原因须与学科相关、能解决、与对策挂钩；是"问题背后的问题"。
> 常见病：与问题无关或重复、与理论/管理/政策/对策无关。

**对策建议写作**：针对原因或问题逐条；与研究对象实际相符；与管理政策有关、有政府责任、有推广价值；可写经验借鉴（非必须）、可讨论必要性；简洁直接。
> 常见病：与问题原因不成体系、空话套话、无可操作性。

**参考范文**：
- 城市基层社会治理中社区减负问题的研究——以西城区为例（第九届全国MPA优秀毕业论文）
- 社会治理视角下广州市老年教育发展研究（第八届）

## 2. 案例分析型
对典型事件在真实情境中深入考察，揭示内在逻辑。

**个案研究设计类型**：本质性个案（单个案，深度描述）、工具性个案（典型案例，一般性解释）、集合性个案（多个案设计）。引自罗伯特·K·殷《案例研究：设计与方法》。

**选题三原则**：
- 典型性与代表性：案例能反映研究问题核心特征，避免极端案例偏差，确保样本覆盖关键概念。
- 数据可获取性：优先选能获丰富一手数据的案例（公开档案、访谈权限），评估数据链完整性（三角验证需文档/观察/访谈多源）。
- 理论抽样策略：按理论需求动态调整，可补"反面案例"检验理论边界；案例数以"理论饱和"为原则，多案例通常 4–10 个。

**选题特点**：新鲜独特、以小见大、贴合经历。

**正文结构**：绪论（背景目的意义+研究进展评述+案例代表性/典型性+问题内容+分析框架与方法）→ 案例描述（≤全文 30%；交代时间地点人物事件起因演化；真实、第一手资料）→ 案例分析（找核心问题→选 1–2 个"定制"理论→方案与问题分析呼应、具体可行）→ 研究结论（由个别到一般，结构化思维，对同类情况的启示）。

**方法组合**：
- 深度访谈：半结构化/开放式，获取关键参与者一手资料，录音逐字转录与编码分析。
- 参与式观察：研究者嵌入环境长期观察（3–6 个月），观察日志模板，关注情境细节与隐性知识。
- 档案资料分析：系统收集年报/会议纪要/内部文件，内容分析法提取关键事件时间线、决策过程；交叉核对不同版本，验证真实完整。
- 问卷调查辅助：结构化问卷（量表题+开放题）补充定量数据，三角互证。

**参考范文**：
- "政策接力赛"创新扩散模式探究——基于Z市旧楼加装电梯治理实践的分析（第九届）
- 精准扶贫背景下的精准识别问题研究——以会泽县拖落村为例（第八届）
- 去行政化背景下行业协会资源获取与自主性研究——以上海市级行业协会为例（第八届，多案例）

## 3. 调研分析型
以某项工作/某类问题/某事件为对象，定性或定量，"去粗取精、去伪存真、由此及彼、由表及里"。

**选题三方向**：
- 描述新发现：总结新情况新实践规律（如政府数字化转型治理绩效）。
- 解释本质机理：发现新公共问题背后机理/原因（如在线合作生产形成动因）。
- 重要性问题：全局性/普遍性/瓶颈性/棘手问题（如重大突发公共事件应急管理制约因素）。

**正文结构**：
- 绪论：背景/目的/意义 + 文献综述与评价 + 调研问题与内容 + 分析框架与研究方法。调研目的分探索性/描述性、理论性/解释性；意义须与背景挂钩。
- 调查方案设计：时间地点对象范围、抽样与调研过程、方法手段（问卷/个案/访谈/数据挖掘）、信度与效度检验、内容环节重难点。
- 调查结果描述：基本数据、重要事实、总体状况，为后续分析做基础。
- 调查结果分析：理论联系实际，揭示机制机理或问题形成机理，用数据分析成因。
- 对策建议：经验升华或针对问题成因提措施；有可行性、适用性。

> 常见病：材料收集方法单一（应多渠道三角互证）；问卷访谈设计缺陷、样本不足或无代表性、非本人发放；缺信度效度检验；标题逻辑不一致；描述不详实不聚焦；不会用数据资料描述；缺理论分析与机理分析；问题与对策两张皮、过于宏观不具体、套路化。

**参考范文**：
- 团队社会资本对科研人员创新实施的影响研究——以中科院M科研院所（第九届）
- T市公安边防警察角色压力对工作投入作用的实证研究（第九届）
- 中国基本养老保险"断保"成因初探——基于Y市的调查分析（第八届）

## 4. 政策分析型
聚焦政策制定、执行、评估、监控（督查）、变迁及政策内容。

**可研究范围**：政策内容（大政方针到各部门具体政策与项目设计）；政策过程某环节或全过程；不同领域/国家/地区政策比较；政策系统或决策体制构成与运行；政策活动者及其行为。

**正文结构**：
- 绪论：选题依据、文献综述、研究内容与思路、研究方法及技术路线。
- 理论基础：阐明理论依据，建构分析框架/评估模型/评估指标体系/比较维度并论证。
- 政策描述：研究政策的背景、内容与演化、相关政策过程环节及实践进展。
- 政策分析：基于框架/模型/指标体系/比较维度，对政策深入分析与全面评估及比较研究。
- 结论：总结发现，对成果拓展、推广或理论提炼与上升。

狭义政策分析（政策规划）四步：确定政策目标 → 找出达成目标的各种可能办法 → 分析每个备选方案的各种可能结果 → 依标准排列备选方案顺序。

**参考范文**：
- 文件制度视角下省级政府政策性公文处理研究（第八届）
- 北京市海淀区创新创业政策的工具结构与演进分析——基于文献计量方法（第九届）

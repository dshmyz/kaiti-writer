# 篇幅档位与字数控制（由用户选择，非写死）

> 北航官方未对开题报告正文做硬性字数规定，只规范格式。为产出既充实又不冗长的稿子，按用户选择的篇幅档位控制每节字数。**档位由用户在定稿前选择：三选一档位，或直接输入目标总字数。**

## 三档总字数（正文，不含封面/目录/参考文献/附录）
| 档位 | 总正文 | 适用 |
|---|---|---|
| 精简 | ≈4000 字 | 时间紧、导师要简版、仅过格式 |
| 标准 | ≈6000 字 | **默认、推荐** |
| 充实 | ≈8000 字 | 追求质量、评审严格、案例/调研内容多 |

## 自定义总字数
用户直接输入目标总字数（如"6000 字"），按下表比例分配到各节；若不输入，用默认"标准"档。

## 各节字数分配（按总字数等比缩放）
下表按 **6000 字标准档** 给出基准目标；其他档位按 (目标总字数/6000) 成比例缩放，四舍五入。

| 章节 / 小节 | 基准目标（标准档） | 说明 |
|---|---|---|
| （一）研究背景 | 700–900 | 由宏观到具体、收束到对象，忌空泛 |
| （二）选题意义（理论/现实/前沿必要性） | 500–700 | 三分展开，各 150–250 |
| （三）文献综述 | 1800–2200 | **全文重头**：现状分类 + 述评指空白 + 引出问题；须"述而有论"、引真实文献 ≥15 条 |
| 二、研究思路与框架（思路+框架+大纲） | 800–1000 | 思路文字链 + 框架说明 + 三级提纲 |
| 三、研究方法与创新之处 | 800–1000 | 每法"名称+对象+工具+步骤+信效度"；创新落六方面 |
| 四、学位论文实施计划 | 300–400 | 分阶段三线表 + 对齐开题/答辩节点 |
| 五、预期目标和成果 | 250–350 | 官方模板无此节但《管理办法》必备；预期目标 + 预期成果分列，忌与选题意义重复 |
| 合计 | ≈6000 | — |

## 执行规则
1. 定稿前（第 0 步收束到题目后、起草前）**用 AskUserQuestion 一次性问清篇幅偏好**：选项"精简/标准/充实"，并把"自定义字数"作为可选项（用户选 Other 输入具体数字）。
2. 起草时把对应档位/自定义总字数换算出的**每节字数目标**，作为该节的篇幅约束，确保"写够不注水"——字数不足就补论据/展开，过多就删枝蔓。
3. 字数统计以**正文汉字**计（不计空格、标点外的符号、参考文献、附录）；文献综述是重点，宁可多不可少（≥1500）。
4. 若用户未明确选择，默认"标准"档（≈6000 字）。

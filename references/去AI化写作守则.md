# 去AI化写作守则（中强度·写稿时对照执行）

> 定位：**在起草/写入模板时就执行**，不是交付后的一次性润色。目标是把"AI 味"清掉、让开题报告读起来像人写的正式学术文档——**清模板腔与空话套话，但保留学术规范的正式感，不口语化**。
> 适用：逐节起草时对照本守则写；逐节质量闸与自查清单引用它复查。

---

## 0. 一句话原则
**"能删则删、能实则实"**——删掉没有信息量的空话套话与机械连接；需要表达的地方给**具体内容**（谁、做了什么、为什么、何结果），而不是叠形容词。

---

## 1. 高频"AI 味"清单（见则替换）
下面这些词/句式一旦出现且不是实义使用，一律删或换成有信息量的表达：

| AI 味表达 | 处置 |
|---|---|
| 技术赋能、多措并举、着力推动、扎实推进、着力抓好 | 删除；若有具体做法，直接写做法 |
| 具有重要意义、十分重要、不可或缺、不可替代（空泛时） | 删除，或说明"对谁、在哪方面"重要 |
| 筑牢……根基、补齐……短板、打通……堵点（成串比喻） | 换直白说法 |
| 进一步、深入、切实、全面、不断、积极（作空修饰语） | 每段留 0–1 个，其余删 |
| 总的来说、综上所述、值得注意的是、不难发现（段首滥用） | 留至多 1 处，且后面须跟实质内容 |
| 三句以上平行排比（"……是……；……是……；……是……"） | 拆开；排比只作强调用在关键处 |
| 每段都以同一种句式开头的机械结构 | 打散段落起手式（陈述/设问/例证交替） |
| "首先……其次……再次……最后"式流水账连接 | 改为内容相关性自然过渡 |
| 引号满天飞（把普通词都加引号） | 仅保留确需强调或术语 |
| 首尾呼应的模板腔（开头提问结尾必答） | 按需，不必刻意对仗 |

---

## 2. 更自然的改写手法
- **句式长短错落**：长句（带因果/转折）与短句交替，避免整段都是等长句。
- **用具体替换抽象**：说"协调难度大"不如"一楼与顶楼业主利益冲突导致常年搁置"（有实例时）。
- **时态与人称一致、避免被动腔**：MPA 开题多用第一人称视角陈述研究设想，顺畅即可，勿处处"应、需、要"。
- **连接词克制**："然而/因此/同时"在真正转折处才用，勿句句都挂。
- **保留个人痕迹**：如果用户有自己惯用的说法/开场习惯，采纳；正文同义表达要变化，不重复用同一批词。

---

## 3. 中强度边界（不要做）
- ✗ 不刻意口语化、不写网络用语、不插入"哈哈""你懂的"之类。
- ✗ 不为了"去AI"而乱断句、无标点到影响学术规范。
- ✗ 不删实质内容——去AI化是改表达，不是删论点和文献。
- ✗ 不做无意义的同义替换（把"研究"全换成"探究"反而是新痕迹）。

---

## 4. 自查触发
起草完每节，对照第 1 节清单快速过一遍；自查清单（A 组）增一条：
> - [ ] 去AI化已执行：无明显模板腔/空话套话/机械排比（用本守则复查）

---

## 5.（可选）用户自备话术 / 偏好例句
本节默认为空，是留给用户的**个性化位**：

- 若用户给了自己的"去AI化"话术、偏好句式或不喜欢的词，**把它记在这里**，之后起草一律优先采用（比第 1 节的通用清单优先级更高）。
- 若用户提供过自己写的段落作为语感样本，也可摘录在此，起草时对齐其句长与用词习惯。
- 没有就跳过——不要为了填满本节去编造规则，也不要因为本节是空的就反复问用户。

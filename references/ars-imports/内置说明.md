# ARS 外部能力导入说明

> 本目录下文件**原样复制**自开源项目 **Academic Research Skills (ARS)**：
> `https://github.com/Imbad0202/academic-research-skills`（v3.19.0 附近版本，2026-08-09 经 GitHub API 抓取，逐字节保留原文，未作删改）。
> **许可**：CC BY-NC 4.0（署名-非商业性使用）。用于本「开题报告」技能（学术写作辅助、非商业）合规。

## 为何导入
ARS 是"人机协作写论文 + 质量把关 + 防 AI 幻觉引用"的成熟方法论。我们的「开题报告」技能只取其**文献综述/检索环节**直接可用的能力，用于**检索真实文献、组织文献综述、筛别低质来源**，不引入其整套论文写作/pipeline/评审架构。

## 各文件与本技能用途映射

| 文件（原样复制） | 在本技能中的作用 | 何时参考 |
|---|---|---|
| `source_quality_hierarchy.md` | 来源质量分级（证据金字塔 7 级 + A–F 打分 + 社科/政策字段调整 + 掠夺性期刊红旗） | 文献综述筛选文献、判定"哪些文献作主证/佐证"时。**尤其"Field-Specific Adjustments"的 Social Science/Policy 分级贴合 MPA** |
| `literature_matrix_template.md` | 文献矩阵：来源 × 主题交叉表，汇总每篇对某主题"支持/反驳"，据此提炼综述的"述而有论"与知识空白 | 整理文献综述前，先把检索到的文献做成矩阵，再动笔写"国内外研究现状/研究述评" |
| `literature_monitoring_strategies.md` | 各学术库可持续文献跟踪的设置（Scholarly/PubMed 等） | 学位论文写作跨多月的追踪用；开题阶段仅可选 |
| `openalex_api_protocol.md` | OpenAlex 检索协议细则：查询模式、标题相似度 0.70 匹配、速率/重试、退化处理 | 用 OpenAlex 补全/核验英文文献元数据时（与 `文献检索.md` 的开放 API 通道配套） |
| `crossref_api_protocol.md` | Crossref 协议细则（DOI 注册表，期刊覆盖最强） | 核验有 DOI 的期刊文献卷期页时 |

## 使用提示（重要）
1. **这些文件来自 ARS，部分引用了 ARS 内部 `scripts/*.py`、`shared/*`、spec 章节等**——那些脚本/spec 并未随本技能导入。本技能只采用这些文件里的**方法论与元数据核验规则**（分级表、矩阵结构、API 查询模式、匹配阈值），不依赖 ARS 的 Python 客户端。若某处提到 `openalex_client.py` 等，可视为背景说明而非可执行依赖。
2. 与技能原创的 `参考文献著录.md`（GB/T 7714）配合：ARS 管"选哪些、质量如何、怎么组织"，GB/T 7714 管"怎么著录"。
3. 检索主流程仍以技能原创的 `文献检索.md` 为准；本目录文件是检索后的**质量分级与综述组织**工具，以及 OpenAlex/Crossref 的**细则补强**。

## 更新方式
ARS 更新后如需同步，可重新经 GitHub API 抓取同名文件覆盖本目录；但请注意 ARS 文件本身在演进，覆盖前先确认新版与技能的其他指引仍一致。

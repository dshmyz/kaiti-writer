# 开题报告自查清单（输出前逐条核对）

> 用途：起草完开题报告后，对着这份清单逐条核验；全过即可定稿。核对时为每条写上「通过 / 需修改（原因）」，需修改的回到 SKILL.md 对应节改后再查一遍。

## A. 7 项必备内容（《管理办法》第三条，缺一不可）
- [ ] 开题题目（清晰、切题、可写）
- [ ] 选题依据（意义 / 必要性 / 前沿性）
- [ ] 文献综述（深入调研 → 系统分析现状 → 指出不足 → 阐述趋势 → 引出拟研究问题）
- [ ] 研究方案（研究目标 / 内容 / 关键问题 / 方法 / 技术路线）
- [ ] 预期目标和成果（官方模板**没有**这一节；默认新增「五、预期目标和成果」置于「四、实施计划」之后、参考文献之前——在 `content_by_section` 里给这个键，脚本会自动建节）
- [ ] 学位论文实施计划（分阶段时间表）
- [ ] 主要参考文献（真实可核验，≥15 篇，近 5 年过半）
- [ ] **去AI化已执行**（写入时即按 `references/去AI化写作守则.md` 落笔，非事后润色）：无"技术赋能/多措并举/筑牢…根基"类空话，无"进一步/深入/切实"充数，无三句以上平行排比，句式长短错落、抽象处已换具体

## B. 逐节质量闸（对应 SKILL.md「逐节质量闸」）
- [ ] **题目可写**：不是"我国XX研究"式的专著级题目（超了按 `references/选题引导.md` 第五节四把刀收窄）；也没窄到撑不起一篇学位论文
- [ ] **没有堆砌**：理论、方法、案例地都砍到"少了它论证就不成立"（多一个方法多一份信效度要交代，多一个理论多一段自洽要圆）
- [ ] **无占位、无自相矛盾、无两种读法**（大纲自查四问的落地检查：方法写问卷样本却说访谈、题目说"以某街道为例"正文却谈全市，都属此项）
- [ ] **研究背景**：由宏观到具体、由远及近，收束到研究对象；与选题意义有逻辑联系
- [ ] **选题意义**：分理论 / 现实意义 + 前沿性必要性；不与背景脱节、文不对题
- [ ] **文献综述**：按主题 / 观点分类梳理（非罗列）；指出研究空白并引出拟研究问题；≥15 篇；近 5 年过半；述而有论、忌堆砌抄书
- [ ] **研究思路**：文字 + 技术路线图，「问题→理论→方法→分析→结论」
- [ ] **研究框架 / 大纲**：各部分解决什么问题、彼此关系；二级或三级提纲
- [ ] **研究方法**：方法名 + 对象 + 工具 + 步骤 + 信度效度；定性与定量结合、三角互证；忌只列方法名
- [ ] **创新之处**：落到六方面之一（解释原则 / 视角、概念与框架重组、提问方式变革、分析方法改变、背景知识更新、逻辑关系转换）；忌「首次研究」空泛
- [ ] **实施计划**：分阶段时间表，对齐节点（硕士第二学年 11 月底前开题；开题至答辩硕士 ≥5 月）
- [ ] **参考文献**：GB/T 7714；真实、元数据完整、可核验；类型码正确（[J]/[M]/[D]/[R]/[N]/[EB/OL] 等）

## B2. 含问卷 / 访谈的额外核（见 `references/问卷与访谈提纲.md`）
> 研究方法里没有问卷也没有访谈，本组整组跳过。

- [ ] **附录已附问卷设计稿 / 访谈提纲全文**（模板硬要求「若论文包含访谈或问卷，须附访谈提纲或问卷设计」，缺了 A 组「附录」也不算过）
- [ ] **没有编造尚未产生的数据**：开题阶段写「拟发放 X 份」「计划访谈 8–12 人」，**不出现回收份数、有效率、Cronbach's α、KMO 的具体数值**（信效度只写拟如何检验）
- [ ] **量表来源已标注**（作者/年份/原量表名；改编说明改了什么），来源不确定的已标「待核验」而非臆造
- [ ] **样本量站得住**：题项数 × 5~10 倍且 ≥200 份；正文写明**由本人发放**
- [ ] **访谈对象已分层**（不能只访居委会书记；基层治理类至少覆盖一线/条线负责人/服务对象三类），并说明抽样理由
- [ ] **逐题过了六条**：无一题两问、无诱导性、无双重否定、无专业术语、选项互斥且穷尽
- [ ] **问卷维度与研究框架对得上**（框架讲三个维度、问卷只测两个属于不一致）
- [ ] **伦理项齐**：卷首语含匿名保密承诺与预计时长；访谈写明知情同意、是否录音、受访者编号匿名化
- [ ] **问卷与访谈不是两张皮**：已说明二者如何三角互证

## C. 篇幅（如已选档位 / 自定义字数）
- [ ] 各节达到目标字数（写够不注水），与篇幅档位一致——`build_from_template.py` 自检会打印**各节中文字数**，直接对照 `references/篇幅档位.md` 的基准区间核
- [ ] 全文总字数符合所选档位（约 4000 / 6000 / 8000 或自定义）
- [ ] **占位已全部清掉**：自检若打印「⚠️ 检出未填占位标记」或「⚠️ N 条仍是占位」或封面「仍是占位」，说明还有 `〈〉`/`TODO`/`待补`/`XXX` 没填——**定稿前必须清零**。注意示例 json 自带 `〈XXX〉` 封面和占位参考文献（它们带 `"_demo": true`，警告会标"示例预期如此"）；照抄示例改成自己的内容时，**要把 `_demo` 这一行删掉**，否则真占位也会被标成预期而漏掉

## D. 格式（参照 `references/格式规范.md`）
- [ ] 字体字号、页边距、行距符合规范
- [ ] 目录已生成；脚本已置 `updateFields`，Word 打开时会提示更新域（选"是"即更新页码；若未提示则手动按 F9）
- [ ] 封面四项（题目 / 作者 / 专业 / 指导教师 / 学院）填写正确
- [ ] 模板末尾「书写规范」说明段已删除（脚本自动处理）
- [ ] 图表、公式、名词术语规范
- [ ] **每张表都有表题且在表上方、每张图都有图题且在图下方**；编号连续（表1、表2…／图1、图2…），正文有"如表1所示""见图1"之类的呼应
- [ ] **技术路线图已落实**：要么已嵌入图片，要么已明确告知用户此处待补图（不得只写"见下图"却无图）

## E. 评审标准（对照）
- [ ] 紧密结合公共管理实践，理论与现实意义重要
- [ ] 前沿问题，具实用或学术价值
- [ ] 充分运用理论与方法解决问题
- [ ] 主题明确、论点清晰、论据充分可靠、分析全面推论严谨、方法先进可行、结论准确、文字精练引证规范
- [ ] 创新六方面占其一

## F. 查重提示（送检前）
- [ ] 已提醒阈值与送检要求（≤10% 直接评阅 / 10–20% 修改后导师签字 / 20–30% 延期 ≥3 月重检 / 30–40% 专家鉴定 / >40% 取消资格）
- [ ] 送检须终稿文本、与送审纸质版一致、每篇原则上限检 1 次
- [ ] 学术诚信：文献不臆造卷期页码，缺项已标注「待核验」
- [ ] **文档属性无他人信息**：Word/PPT「文件—属性」里的作者、单位、最后修改人不该是别人的名字或邮箱（脚本已自动清，**但若用户在 Word 里另存过、或用了自带模板另一条路径生成，需再看一眼**）

## G. 文献检索完整性（如做过联网检索）
- [ ] 已按 `references/文献检索.md` 检索并整理真实文献
- [ ] 检索真缺时已按分级处理，并如实告知用户哪些渠道受限、哪些条目元数据待核验
- [ ] 如需补全（尤其中文 CSSCI），已告知用户在校园网 / 知网补齐清单

## 把结果输出给用户（起草完回显格式）
核对完后，把清单结果**呈现给用户看**（不是内部自评），格式如下——逐条列出、每项带 ✅/⚠️，结尾给结论与修改建议：

```
## 开题报告自查结果

### A. 7 项必备内容
- [x] 开题题目 ✅
- [x] 选题依据 ✅
- [x] 文献综述 ✅
- [ ] 研究方案 ⚠️（研究"关键问题"未单列，建议补一句）
- [x] 去AI化已执行 ✅

...（各组以此类推）

### 结论
✅ 全部通过，可交付　／　⚠️ 存在 2 项需修改：
1. 研究方案——关键问题未单列 → 建议：在（分析框架）一节补明"拟解决的关键问题"。
2. （可继续列出）

是否需要我据此修改后再复查一遍？
```

要点：
- **不省略、不笼统**：别只说"已自查/基本通过"，要把每项勾选状态和 ⚠️ 项的具体原因、改法都列出来；
- **能给修改建议的都给**，并主动问用户是否据此修订后复查，形成闭环。

# 一站式收尾（自查通过后的可选交付物）

用 **AskUserQuestion 多选**问用户还需要哪些交付物，**明确告知"都不需要也可以，直接结束"**。用户选了哪几项就做哪几项，逐项交付并给出文件路径；未选的不做、不追问第二遍。

## 1. 汇报 PPT

先问用哪套内置模板——`模板1` / `模板2` / `模板3`（均为北航答辩通用、16:9，见 `assets/templates/ppt/`），或"不用模板，只要 markdown 大纲"。

**选定模板后先做依赖前置检查**（生成前跑一次，别等报错）：

```bash
python3 -c "import pptx; print('python-pptx', pptx.__version__)"
```

若报 `ModuleNotFoundError`，**用 AskUserQuestion 问用户是否安装**（不要擅自装、也不要静默放弃），选项给三个：

- 「安装（推荐）」→ 征得同意后执行 `pip install python-pptx`（或 `python3 -m pip install python-pptx`），装完复跑检查再生成；
- 「不安装，改为 markdown 大纲」→ 直接产出逐页 PPT 大纲（每页标题 + 要点），用户自己粘进 PPT；
- 「跳过 PPT」→ 不做这项，继续收尾其他选项。

检查通过后，把内容写成 PPT 用的 json（`title` / `cover{作者姓名,指导教师,日期}` / `chapters[{name, slides[{title, bullets}]}]`），执行：

```bash
python "$SKILL/scripts/build_ppt_from_template.py" \
  --template "$SKILL/assets/templates/ppt/模板1-北航答辩通用.pptx" \
  --content ppt_content.json \
  --output "开题汇报-<题目>.pptx"
```

脚本"改而不建"：只挑模板里需要的页、替换占位文字、复制内容页给各章、删除未用页并按 封面→目录→各章(章节页+内容页)→致谢 重排；自动清除模板作者水印与装饰样例文字（"JUNE 12th""XX""小标题一"等）。生成后打印自检（页数/题目/章节数/水印/残留占位），把自检结果一并回显给用户。**只用 skill 内置副本，勿改工作目录里的原模板。**

> 依赖 `python-pptx`。上面的前置检查是为了**先问用户、而不是先报错**；若仍撞上，脚本会打印安装命令与降级建议并以退出码 1 干净退出（不生成半成品文件）。任何情况下都**不要因为缺依赖卡住整个流程**——问清用户意愿后走安装或降级。

## 2. 汇报演讲稿

生成时先问**时长与形式**（如 8/10/15 分钟；逐字稿 or 提纲式提示卡），按篇幅折算字数（口播约 200–240 字/分钟），逐页对应 PPT，同样按 `references/去AI化写作守则.md` 写成口语可讲的稿子（此处允许比正文口语化）。

## 3. 答辩问答预测

按"评审标准 + 优秀标准 + 本文薄弱处"预测 10–15 个高频问题（选题价值、概念界定、理论适配、方法可行性、样本代表性、数据可得性、创新点成立性、对策可操作性等），每题给要点式答法；对确实是弱点的，**如实提示补强方向而不硬辩**。

## 4. 多份格式导出

按需再产出 markdown 全文 / 纯文本 / 提纲摘要，便于贴到邮件或系统表单。
